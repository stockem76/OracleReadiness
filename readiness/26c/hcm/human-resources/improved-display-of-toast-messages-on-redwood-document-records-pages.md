# Improved Display of Toast Messages on Redwood Document Records Pages

`⚙️ Steps to Enable`

> 📖 [View on Oracle Help Center](https://docs.oracle.com/en/cloud/saas/readiness/hcm/26c/hure-26c/26C-hr-wn-f50113.htm)

Redwood Document Records pages now display toast messages more prominently, making user feedback easier to see after actions such as adding a document record or running a mass download process. This enhancement improves how toast messages are displayed on Redwood Document Records pages, making notifications easier for users to notice.

For example, when a user updates a document record, a toast message appears in a more noticeable location, so the user can immediately see that the action has completed successfully without having to search for confirmation elsewhere.

Users get clearer on-screen feedback after completing actions on document records, which helps them confirm outcomes more quickly and continue working with less uncertainty.

## ⚙️ Steps to Enable and Configure

You don't need to do anything to enable this feature.
